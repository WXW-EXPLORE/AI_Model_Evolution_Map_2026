# AI Model Evolution Map 2026 · 模型演化地图

**版本时间：2026-11-13。** 一份离线、可交互的 AI 模型演化地图，面向 AI 工科研究者。

## 使用方法

解压 ZIP，双击 `index.html` 即可在 Chrome、Edge、Firefox 或 Safari 打开。无需 Python、Node、npm、联网或其他依赖。资料来源链接在联网后可点击打开。

## 核心导航

- **一眼总览（首页顶部）**：十大家族 × 2023/2024/2025/2026 年度代表模型，直接看到机构、出现顺序与领域彩点。
- **模型演化地图（首页下方）**：横轴为公开发布月份，纵轴为组织/家族，节点显示专项能力定位，单击查看详细介绍、架构、开放方式、原始资料。
- **特长领域矩阵**：家族与推理、编程、视觉、多模态、长上下文、效率、Agent、中文/多语、开放可研究、科学等交叉标签。
- **Agent/Harness 演进**：将 Agent Harness 与基础模型分离观察。
- **Benchmark 演进**：按评测对象分泳道，识别模型基准与系统基准的区别。
- **科研阅读指南**：实验控制、开放权重与完整开放、血缘识别、防止性能伪比较。

## 最重要的使用原则

1. **横轴代表何时公开**。发布时间不同于预训练完成日期，也不代表模型对外长期可用。
2. **纵轴代表谁做的**。不同机构的同名技术相似不代表参数/数据/架构直接传承。
3. **颜色小点代表该模型官方/技术文档中的研究路线或主要能力定位**，而不是统一 Benchmark 实验分数。空白也不代表模型不具备某项能力。
4. 连线只连接**同一模型家族连续里程碑**，表示产品谱系和时间演进，不证明前后是基于同一权重继续训练。
5. 2017–2026 的里程碑是**精选而非穷尽**。例如 2026 的每月小版本、特定领域分支很多，不全收录；重在一眼看出主要路线与源流。
6. 开放权重、开放模型、完全开放的许可/代码/数据/中间检查点要求不同。详情中的公开方式仅是概览，实际许可请检查具体模型卡。
7. 个别早期技术/项目时间只精确到月份，可能是论文首发、官方公开或公共代码发布日期；不要当成准确到日的历史证明。

## 文件

- `index.html`：主网页
- `styles.css`, `app.js`, `data/embedded.js`：可直接打开的离线资源
- `data/atlas.json`：完整结构化知识图谱（96 模型里程碑 + Harness + Benchmark）
- `data/models.csv`, `data/harness.csv`, `data/benchmarks.csv`：可导入表格分析的软件数据
- `SOURCES.md`：官方来源与研究解释说明

在页面右上角可以导出当前时间图到 SVG，适合放入 PPT、论文草图进一步修改。
